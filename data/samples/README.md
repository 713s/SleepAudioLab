# Public sleep-audio test samples

## snoring_cc0.ogg

- **Source:** [Wikimedia Commons — Snoring of old man.ogg](https://commons.wikimedia.org/wiki/File:Snoring_of_old_man.ogg)
- **Author:** Saaabaaato
- **Date:** October 2026 (Commons file page)
- **License:** [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- **Duration:** Approximately 60 seconds
- **Description:** A real recording described by its uploader as snoring.
- **Modifications:** None; the download script preserves the original Ogg container bytes.
- **Source download:** https://commons.wikimedia.org/wiki/Special:Redirect/file/Snoring_of_old_man.ogg

This file is intended for waveform, STFT, FFT, audio-loading and exploratory snore-event examples. It is **not** a curated clinical data set, is not annotated with validated event boundaries, and should not be used as evidence of apnea, clinical sleep stages, or diagnostic accuracy.

Use `python scripts/fetch_public_snore_sample.py` to fetch the original recording when the sample is not checked into the repository. The release of this file under CC0 applies to the sample, **not** to all other code or assets in SleepAudioLab.
